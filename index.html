⚡ Cara Pakai
1
Tulis atau paste teks
Masukkan teks apapun di kolom Input Teks. Bisa huruf, angka, simbol.
2
Siapkan konfigurasi JSON
Format: [{"abjad":"a","trans":"AAA"},...]

abjad = karakter asli  |  trans = penggantinya.
3
Upload file JSON (opsional)
Klik area upload atau drag & drop file .json. JSON default sudah tersedia dan siap dipakai langsung.
4
Klik Transform
Tekan tombol Transform atau shortcut Ctrl+Enter. Hasil muncul seketika.
5
Salin hasil
Klik tombol Copy di pojok kanan output untuk menyalin ke clipboard.
Tips: Transformasi bersifat case-sensitive — a dan A dianggap berbeda. Karakter yang tidak ada di JSON akan dibiarkan seperti semula.
